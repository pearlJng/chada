# CHADA

동네 식당 새벽 냉장 공동배송 서비스 랜딩페이지 (가상 브랜드, 포트폴리오용).

- 기획 기준: `CLAUDE.md`
- 비주얼 가이드: `DESIGN.md`
- 페이지: `index.html` · `style.css` · `script.js` · `asset/`
- 참고용 단독 프로토타입: `prototype/` (이미지가 파일 안에 들어 있어 따로 열어볼 수 있음)

## 로컬에서 보기

```
python3 -m http.server 8000
```
브라우저에서 http://localhost:8000

## 배포

GitHub Pages → Settings → Pages → Branch: `main` / `(root)`
